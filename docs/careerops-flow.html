CareerOps — Job Hunting Automation Pipeline

Python (JobSpy + Gupy/Workday + InHire) → filtros + perfil → IA → Sheets (Candidatar/Auditoria) + Telegram + Digest | Cron scheduler

Collection

  • • Cron: multi-horário (países via config.json)
  • • CLI: --country, --countries, --all, --source
  • • JobSpy: LinkedIn + Indeed
  • • banks.py: Gupy (Itaú/Sicredi/BMG) + Workday (Santander)
  • • inhire.py: portais InHire (164 tenants) + discovery crt.sh/Wayback
  • • profile.yaml → profile.py (fonte de verdade)

Filtering & IA

  • • Blocklist (título/descrição/empresa)
  • • Dedup: URL + empresa/título/localização
  • • BR: remoto + híbrido ✓ / presencial ✗
  • • IA (DeepSeek/OpenAI) pontua 0-100 vs currículo
  • • Pré-filtro por título + det_score (final = max(IA, det))

Outputs

  • • Sheets: >71 → "Candidatar"
  • • Sheets: ≤71 → "Auditoria"
  • • Telegram: vagas aprovadas
  • • Digest (sep.): resumo 21h
  • • Currículo PT/EN auto-gen (workflow separado)
